# Recruiter Overview

## Shopee Deal Machine V7.1

Projeto prático de automação e integração multicanal para descoberta, análise e distribuição de ofertas.

### O que este projeto demonstra

- Desenvolvimento backend com Python e FastAPI.
- Integração com APIs externas.
- Automação de processos e filas de trabalho.
- Coleta e tratamento de dados vindos de fontes autorizadas.
- Integração com Telegram e WhatsApp.
- Regras de deduplicação, retry, cooldown e idempotência.
- Curadoria automática baseada em score e filtros de qualidade.
- Persistência com SQLAlchemy e SQLite, com arquitetura preparada para PostgreSQL/Redis.
- Interface web administrativa.
- Scripts de operação e troubleshooting para Windows.
- Deploy com Docker em Linux.
- Testes automatizados e CI com GitHub Actions.

### Integrações

- Shopee Affiliate Open API
- Telegram Bot API
- Telethon
- Evolution API v2

### Cuidados de segurança

Este repositório de portfólio não contém credenciais reais, bancos de produção, sessões do Telegram ou arquivos de runtime. Segredos são fornecidos apenas por variáveis de ambiente e os exemplos públicos usam placeholders.

### Papel no portfólio

O projeto representa experiência prática em desenvolvimento, automação, manutenção, debugging, integração entre serviços e evolução contínua de produto.
